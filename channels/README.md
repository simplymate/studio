# Kanäle des Updaters / Updater channels

`stable.json`, `beta.json` und `internal.json` beschreiben je Kanal die aktuelle Fassung. Sie schreibt `release.sh promote`, manuell durch den Betreiber freigegeben.

`stable.json`, `beta.json` and `internal.json` describe the current version of each channel. They are written by `release.sh promote`, released manually by the operator.
